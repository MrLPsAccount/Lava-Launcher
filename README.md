# 🔥 Lava Launcher

Lava Launcher is an independent, Steam-inspired Minecraft: Java Edition launcher for Windows, designed to bring everything Minecraft into one place. It features an integrated Modrinth Store for discovering mods, modpacks, shaders, and resource packs; a customizable Library for managing worlds, multiplayer servers, and Minecraft versions; live server information; screenshot management; customizable themes; and backup functionality. Lava also aims to support Microsoft account authentication, direct Minecraft launching, and automatic mod installation. The project is currently in active development and is not affiliated with Mojang Studios or Microsoft.

**Status:** Experimental desktop source (v0.10.1). Microsoft/Minecraft authentication requires an approved application registration; direct authenticated launching has not been fully tested. See [development notes](DEVELOPMENT.md).
